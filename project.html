B2B SaaS · Lead Generation · AI Outreach

EMOL

The B2B Client Acquisition Engine

EMOL automates the hardest part of business growth — getting clients. It hunts qualified leads via Google Maps, scores them by potential, then uses AI to write and send personalized cold outreach that actually converts.

The Problem

Customer acquisition is the hardest and most expensive part of business. Most companies waste hours on cold outreach with near-zero conversion rates.

The Solution

A PHP/MySQL system that finds qualified leads via Google Maps, scores them by digital presence, then fires AI-personalized outreach in a single click.

PHP Core MySQL OpenAI API Google Maps API REST Routing Lead Scoring A/B Testing
AI writes personalized emails in seconds
Hunts businesses with no web presence (highest-value leads)
Real-time analytics: open rate, reply rate, click tracking
A/B testing for subject lines and body copy

Flutter App · Design Studio · Mobile-First

TEMPLIX

The Professional Design Studio

TEMPLIX is a full Flutter production app that gives mobile-first creators a desktop-grade design studio in their pocket. 25 content templates, 35+ fonts, 9 design styles, real-time generation — all in one fluid interface.

The Gap

High-tier graphic design tools are locked to desktop. Mobile-first creators needed a production-grade design studio built for their workflow.

The Solution

A full native Flutter app with superior typography, custom canvas engine, 9 design styles, and a complete image editor — rivaling desktop tools on mobile.

Flutter Dart Provider Google Fonts Custom Painter SharedPrefs Image Editor
9 design styles: Bold, Elegant, Minimal, Neon, Retro, Brutalist, Corporate, Organic
35+ Google Fonts with live preview and category browser
Full image editor: filters, adjustments, crop, effects
Export in 6 formats × 4 resolutions, with watermark control

Restaurant Management · Real-Time Ops · AI Assistant

PEACESPOT

The Nigerian Restaurant Operating System

PeaceSpot replaces the WhatsApp-and-notebook workflow most Nigerian restaurants run on. It gives customers live order tracking, loyalty rewards, and an AI assistant to help them order — while managers get a real-time dashboard for staff, orders, and broadcasts.

The Problem

Small restaurants take orders over WhatsApp and track everything on paper — no live status, no repeat-customer rewards, no visibility for the manager on the floor.

The Solution

A full PHP/MySQL platform with separate customer and manager dashboards, live order status, push notifications, a loyalty engine, and Nara — an AI assistant that helps customers order.

PHP Core MySQL Gemini API Web Push / Service Workers Short Polling Session Auth InfinityFree Hosting
Live order status, from kitchen to table
Nara, an AI assistant (Gemini API) that recommends dishes and answers menu questions
Loyalty points system that rewards repeat customers
Manager dashboard for staff, orders and broadcasts
Web push notifications even when the browser tab is closed
